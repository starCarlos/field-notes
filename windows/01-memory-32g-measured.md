# 32G 内存实测：网上那两处数字，差了我 8 倍

> 存档 ｜ 素材日期 2026-11-13 ｜ 来源：个人实测记录
> 四问：AI 编得出吗？编不出，进程数和 MCP 子进程数是本机跑出来的 ／ 有试错过程吗？有，先信网上数据，再被本机打脸 ／ 有数字或可复现报错吗？有，PowerShell 归并进程树，数字可复跑 ／ 半年后还有人踩吗？会，内存不够是长期问题

## 现象

同时开 Codex、Claude、WorkBuddy 三个桌面版，加微信、QQ、uTools、UU 远程、Chrome、VSCode。想知道 Mac 16G 和 Win 32G 各占多少，跨平台是不是真差一截。

## 我以为是 X

以为 Mac 更省内存。同一个应用，Mac 1.1G、Win 1.5G，看着像省了三成。以为 uTools 就是个六十来兆的小工具。以为微信纯聊天两百多兆。

## 实际是 Y

三个都错。

**一，跨平台数字不同，主要是统计口径不同。** Windows 任务管理器算工作集，共享 DLL 每个进程各算一遍；macOS 活动监视器算 footprint，共享库只算一次。同应用 Win 1.5G / Mac 1.1G 是口径差，不是真省 30%。

真差距只在「可预取」类应用上。Tom's Guide 测 Chrome 开 20 个标签：Mac 1.67GB，Win 4.76GB；Photoshop 两边几乎一样，3.86 对 3.85。

**二，uTools 网上 60–112MB，本机实测 920MB，差 8 倍。** 网上测的是裸装启动，装插件、开窗口之后完全是另一回事。

**三，微信 220MB 是纯聊天。** 开小程序后，WeChatAppEx 单独就 1GB 起。

## 顺带算的：mini 加外设省不出钱

16+512 档，Mac mini 加键鼠加屏幕，和 MacBook Air 13 比价。

官网价：mini 16+512 ¥8,499，Air 13 M5 16+512 ¥9,999。配件：Studio Display ¥11,999 起，妙控键盘 ¥899 起，妙控鼠标 ¥549。

总价：mini 极限省钱（千元 4K 屏 + 200 键鼠）¥9,647，只比 Air 便宜 ¥352；均衡配置 ¥10,798，反而贵 ¥799；全苹果原厂 ¥22,296，贵 ¥12,297。

苹果的定价就是在逼你买 Air——Air 自带屏、触控板、摄像头、麦克风、四扬声器、电池。mini 唯一真香场景是**已有显示器和键鼠**，或者需要长时间满载（mini 有风扇）。

（另有一组用户自报价 ¥3,800 / ¥7,100，差价 3,300，结论会反转。但两个不是同代同配置：M4 mini 16+256 对 M5 Air 16+512，且 3,800 那台保修已过。**这组数来源未验证**，只能当参考。）

## 怎么测的

PowerShell 读 `Win32_Process`，再按父进程链归并成进程树，按根进程分组统计。机器是一台 Win11 笔记本，32GB 内存。

## 结论

三个 agent 是这批里最重的单项，各 1.5G 起步。

这套组合折算到 Mac 16G 约 13.3GB / 16GB，83%，余量只剩 2.7GB，跑不动，长期黄色内存压力，swap 常驻 2–4GB。Win 32G 余 10.5–13.6GB，全程宽松。

Mac 16G 要跑这套只能做减法：三个 agent 只留一个常驻（省 1.5–3G）、Chrome 换 Safari、清 WorkBuddy 历史工作空间、每周重启微信和 WorkBuddy。

## 能拿走的 3 条

1. **跨平台比内存先看口径。** 工作集和 footprint 不是一回事，差 30% 以内先别下结论。
2. **网上的占用数字默认是裸装。** 装插件、开窗口、挂历史会话之后，量级会变。uTools 差 8 倍，微信差 5 倍。
3. **16G 跑三个 agent 是硬伤。** 不是优化能解决的，只能减常驻。
