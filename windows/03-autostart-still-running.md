# Run 里禁用了，进程照样常驻：微信输入法开机就吃 1.2 GB

> 存档 ｜ 素材日期 2026-11-17 ｜ 来源：个人实测记录
> 四问：AI 编得出吗？编不出，这是本机实测的进程清单和内存数字。/ 有试错过程吗？有，先以为「禁用＝不启动」，逐个对启动来源才对上。/ 有数字或可复现报错吗？有，1229 MB → 833 MB、649 → 608 MB 这一串。/ 半年后还有人踩吗？会，Windows 自启本来就不止一条路径。

## 现象

任务管理器的「启动」页里，HKCU 的 Run 键下大部分项早就点了禁用：QQ、微信、uTools、MuMu、壁纸引擎、百度检测、Edge 自启。

可开机之后，任务管理器里还是一堆进程：Edge 5 个，WPS 两个，微信输入法一串 WebView。禁用标记明明在，进程照样跑。

我的诉求只有一句：软件只在用的时候才有进程。

## 我以为是 X

以为「启动项里禁用」＝这个软件开机不启动。任务管理器那个「禁用」按钮，我当成对软件的总开关。

## 实际是 Y

`StartupApproved\Run` 里的禁用标记，只对「Run 键这一条启动路径」有效。软件还有别的路能起来：

- **Edge**：带 `--no-startup-window` 参数，启动增强在后台预加载，跑着 5 个进程
- **WPS**：没开文档时也有 `wps.exe` 和 `wpscloudsvr silentautologin`，云办公常驻
- **微信输入法**：`wetype_update` 挂着 2 个 WebView
- **MuMu**：`MuMuRemoteService` 是自动启动的系统服务，结束进程后 3 秒内重新拉起

Run 键禁用管不住这些。要么去各软件自己的设置里关，要么改服务。

## 怎么定位到的

按软件把常驻进程汇总，再对每个进程找它的启动来源。来源一共四类：Run 键、自动服务、计划任务、自己拉起自己。

四条逐个对，才看出来哪些不是从 Run 来的。

关的方式是写 `StartupApproved\Run` 禁用标记，和任务管理器里点「禁用」等价，Run 项本身还在。改之前备份到 `%USERPROFILE%\注册表备份`。

## 修法 / 结论

- 只关了 WorkBuddy（这次新关）、Steam、Discord（这两项本来就是禁用）。**没改任何服务**，荣耀电脑管家没动。
- 结束 Edge 后台 5 个进程 + WPS 后台（`wps.exe`×2 + `wpscloudsvr`），约 150 MB，复核没有再拉起来。
- 腾讯会议已经自己退出了。
- MuMu 结束后 3 秒内被 `MuMuRemoteService` 重新拉起。想让 MuMu 只在用的时候跑，光关 Run 项没用，得把 `MuMuRemoteService` 改成手动启动（需要管理员），还要验证火影脚本仍能拉起 MuMu。
- Edge、WPS 要到各自设置里关掉启动增强和云办公，否则下次开机还会回来。

## 顺带查的第二个问题：微信输入法 1.2 GB

同一台机器上，微信输入法 3.0.2.44 占了 17 个进程、1229 MB，已经连续跑了几天。

按专用内存拆开，再结束 server、update、renderer（保留 `wetype_service`，由它重新拉起）做前后对比：

- **`wetype_update` 带 13 个 WebView2 子进程：649 → 608 MB，基本不变。** 它预加载了 `voice_summary\full` 和 `voice_summary\mini` 两套网页（语音总结功能），一启动就占满，不用也常驻。这是**设计上的固定开销**，重启也降不下来。
- **`wetype_server` 引擎：482 → 209 MB**；**候选窗口 `wetype_renderer`：96 → 13 MB**。这两部分会随打字增长（词库按需加载、加缓存）。

后来在输入法设置里把相关开关关了再复测：两个 WebView 照样加载，合计 852 MB，**开关无效**。只结束 `wetype_update`，`wetype_service` 约 5 秒内连同网页一起重新拉起，结束它也没用。

另外，设置窗口本身也挂在 `wetype_update` 下面，开着时会再多开一套 WebView（约 6 个进程、190 MB）。

**结论：3.0.2.44 的内存底线大约 850 MB（网页约 630 + 引擎约 210），只有换输入法才能降。** 剩下的变量只有引擎随打字增长了多少，需要过一段时间再测一次。

顺带发现：`C:\Program Files\Tencent\WeType\` 下留着 9 月升级前的旧版本 `2.1.4.6.tmp0` 和 `WetypeCore_2.1.4.6.tmp0`，共约 409 MB 磁盘，没有进程在用，删除需要管理员。

## 能拿走的 5 条

1. **「启动项禁用」只管 Run 这一条路径。** 服务、计划任务、软件自己的启动增强，各走各的。禁用完还看到进程，先问「它是从哪条路起来的」。
2. **看内存高用专用内存（PrivateMemorySize），别用工作集。** 工作集会把共享页算进来，数字虚高。
3. **WebView2 子进程要按父进程归到宿主名下。** 否则这些内存会算到「Microsoft Edge WebView2」头上，冤枉 Edge。
4. **固定开销和泄漏要分开。** 重启也降不下来的那部分，是设计成本，别去修。
5. **结束进程前先想清楚谁负责拉起它。** `wetype_service` 5 秒拉起，`MuMuRemoteService` 3 秒拉起。不掐掉拉起方，结束多少次都白搭。
