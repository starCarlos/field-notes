# Windows 卸载残留：只读扫了 7 类位置，清出 7.3GB

> 存档 ｜ 素材日期 2026-11-17 ｜ 来源：个人实测记录
> 四问：AI 编得出吗？编不出，9.4GB 的安装拦截日志和 83 个 txt 是扫出来的 ／ 有试错过程吗？有，脚本自定义函数名撞上内置别名，一个目录都没删掉 ／ 有数字或可复现报错吗？有，盘符可用空间前后对比 ／ 半年后还有人踩吗？会，Windows 残留是长期问题

## 现象

C 盘越来越满。想清，但不知道哪些能删、哪些是在用的。先只读扫一遍，不删任何东西。

## 我以为是 X

以为残留主要在「卸载没卸干净」——卸载列表里挂着失效条目、服务没删、计划任务还在。

## 实际是 Y

**服务、驱动、计划任务、卸载列表，全都没有失效条目。**

残留集中在三处：

1. **日志膨胀**。最大单项是荣耀电脑管家的安装拦截日志 `C:\ProgramData\HonorSDK\Records\abinstall`，9.4GB，83 个 txt，单个最大 1.3GB。普通用户对该目录只有读权限，**没删成**。
2. **已卸软件的 AppData**。Notion、CherryStudio、Agents Anywhere、DSH Desktop 的用户数据共 2.0GB。
3. **死启动项**。HKCU Run 里两条、一个 OpenClaw 启动脚本、4 个死快捷方式、2 个空目录。

同时要分清「看着像残留、其实在用」的：`C:\ProgramData\Comms`（6.2GB）和 `QI-ANXIN*` 都属于在用的荣耀软件；微信缓存目录（十几 GB）是微信 4.x 的 `xwechat_files`，在用。

## 怎么测的

PowerShell 只读扫描，7 类位置：

1. 卸载列表
2. AppData / ProgramData / Program Files / 软件安装盘 的一级目录体积
3. 服务与驱动
4. 计划任务
5. Run 键
6. 启动文件夹
7. 开始菜单与桌面快捷方式

按「可放心删 / 已卸软件数据 / 要判断」分三档报给本人，本人选「清 A 和 B」。

## 两档的区别和风险

**A 档：可放心删。** 纯缓存和失败副本，删了不影响任何软件运行。这次删了 TEMP 3.9GB（跳过 24 小时内和 `claude/` 目录）、软件安装盘上一个 DSH 升级失败副本 1.06GB、hclaw-pyinstaller 的 5 个 `_MEI*` 共 1.0GB、5 个 updater 安装包缓存 1.5GB。风险接近零，代价是下次启动慢一点。

**B 档：已卸软件的数据。** 软件本体没了，数据还留着，删了不可逆。这次是 Notion、CherryStudio、Agents Anywhere、DSH Desktop 共 2.0GB，**进了回收站，没直接删**。风险是「万一还想装回来」。另外注意：进回收站不等于释放空间，清空回收站才算。

**C 档（本次没动）：要判断的。** 比如那个 9.4GB 的荣耀日志，得先确认是不是还在写；普通权限删不掉，要管理员。

## 结论

清理前后：C 盘可用约 390 → 约 396 GB，D 盘约 76 → 约 77 GB。

后来本人用管理员身份删掉荣耀日志（abinstall 剩 0 个文件）和 HKLM 里王者万象棋的失效 Run 项，又删了应用宝的 Androws（3 个目录 3.6GB + 30MB + 212MB，一个服务，HKCU/HKLM 各一个键，**没有自启项、计划任务和驱动**）。最终 C 盘约 406GB、D 盘约 80GB。

## 能拿走的 4 条

1. **先只读扫，再决定删什么。** 分三档报给本人选，比一上来就删安全得多。
2. **PowerShell 脚本里别把自定义函数叫 `Del`。** 它会被内置别名 `del → Remove-Item` 抢先解析：单个文件照删，目录在非交互模式下报 NullReference，一个也删不掉。
3. **批量删完必须逐项 `Test-Path` 复核。** 不能只信脚本自己打印的结果。
4. **改系统 PATH 别用 `[Environment]::SetEnvironmentVariable`。** 它会把注册表类型写成 REG_SZ，`%SystemRoot%` 就不再展开。要用 `GetValue('Path',$null,'DoNotExpandEnvironmentNames')` 读出，再 `Set-ItemProperty -Type ExpandString` 写回，改前先备份。
