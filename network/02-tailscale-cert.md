# Tailscale 报「已接受监听，但未签发公网 HTTPS 证书」：开关明明都开着

> 存档 ｜ 素材日期 2026-11-16 ｜ 来源：个人实测记录
> 四问：AI 编得出吗？编不出，报错原文和 `set-dns: context canceled` 是从本机日志里抠的。/ 有试错过程吗？有，Cloudflare → Tailscale → iroh → 撞上证书报错 → 逐个排开关。/ 有数字或可复现报错吗？有，`1603`、`1.104.7`、`set-dns: context canceled`。/ 半年后还有人踩吗？会，私有组网和 Funnel 是两条路，证书还要单独开。

## 现象

需求很简单：人不在电脑前，用 Android 手机打开电脑上跑的那个 Web 服务。

选了 Tailscale。装完、手机配对、点连接，地址打不开，弹出来一句：

```
Tailscale 已接受监听，但未签发公网 HTTPS 证书，该地址暂时无法访问。
请重新连接；若持续失败，请确认此 tailnet 已启用 HTTPS 证书。
```

「已接受监听」和「暂时无法访问」摆在一句里，很别扭。服务明明起来了。

## 我以为是 X

以为管理台的 HTTPS 证书开关没打开。理由很直接：报错最后一句就是让你「确认此 tailnet 已启用 HTTPS 证书」。按字面读，就是没启用。

## 实际是 Y

开关是开的。MagicDNS 开着，HTTPS Certificates 也开着。

卡点在申请流程本身。本机日志显示，证书申请走到 DNS 验证这一步，请求被取消了：

```
set-dns: context canceled
```

**不是「没开证书」，是「开了但没签下来」。** 监听和签发是两件事，报错文案把它们塞进了一句。

还有一层没挑明的区别：这次用的不是纯私有组网，是插件自带的 **Funnel 公网通道**。私有组网只在登录同一账号的设备之间开放，不用域名也不用公网隧道；Funnel 是把服务开成公网入口，必须有公网证书。两条路要求不同，我按前者的印象去排后者的错。

## 怎么定位到的

**拆两层。** 「已接受监听」说明进程起了、端口在听；「未签发证书」说明 TLS 那层没完成。打不开是第二层的事，后面就不用翻端口和防火墙。

**读日志。** `set-dns: context canceled` 的意思是：申请提交到 Tailscale 控制服务、要写 DNS 验证记录时被取消。这句只能证明「没走完」，证明不了「为什么」。

**排掉最容易被误导的那项。** 让人去 `login.tailscale.com/admin/dns` 看 MagicDNS 和 HTTPS Certificates 下的 Enable HTTPS。回答：「都是开着的」。

到这里只能下一个结论：签发没完成，原因在开关、网络、还是等待超时之间，**没定**。会话里也是这么说的，没硬猜。接着查插件的证书申请流程，素材到这儿结束。

同场还有个坑：这台 Windows 装 Tailscale 返回 `1603`（`Tailscale installation failed: 1603`），需要管理员授权。中途下载校验失败过一次，报 `Installer signature invalid`，又重下了 `tailscale-setup-1.104.7-amd64.msi`。

## 修法 / 结论

**素材缺口：最后怎么解决的、换成了哪条路，都没记录。** 会话停在「我继续检查它的签发状态」。

能确认的只有判断：卡在证书签发，不是监听，也不是开关。往下走得看插件申请证书那段的请求和返回，不是再让人去点开关。

当时摆上桌的几条路，素材里都有说法：

- **Tailscale 私有组网 + Serve**：登录同一账号，网页只在这组设备之间开放，不用域名或公网隧道。
- **Funnel 公网通道**：就是这次踩的这条，要公网证书。
- **Cloudflare 命名隧道**：给固定域名，但普通全球网络没有中国大陆数据中心，大陆访客会连境外节点；Quick Tunnel 更适合临时试用，维护者说长期容易断连。
- **iroh**：扫码配对，优先直连，打不通走中继；不用域名、VPS、Tailscale 账号，也不装 VPN 客户端。实验功能，手机要 Android 10+、64 位、带 `-iroh.apk` 的完整版，大陆连通性得实测。
- **自建 FRP + VPS**：电脑主动连 VPS，不必把端口暴露到公网，代价是维护 VPS、域名和证书。

选哪条看「给谁访问」：只给自己手机用，私有组网够；要给别人打开，才需要证书那条路。这次是拿着「只给自己用」的心智模型，去调一个「对公网开放」的通道。

## 能拿走的 5 条

1. **「已接受监听」只说明服务在听，不等于证书签好了。** 一句报错里塞了两层状态，拆开读。
2. **报错最后一句给的建议，不一定是原因。** 让你去开开关，是因为那是唯一能自助检查的项。
3. **私有组网和 Funnel 是两条路。** 前者不用域名和公网证书，后者要。先定「给谁访问」。
4. **`context canceled` 只能证明没完成，证明不了为什么。** 别拿它当结论，也别拿它去改配置。
5. **`1603` 是 Windows Installer 的通用失败码。** 这次对应没管理员权限。装不上先看权限。
